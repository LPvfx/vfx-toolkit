# Radar

A weekly digest of generative AI, computer vision and ML that matters for VFX,
CG, realtime and projection work. It favours things with open code or weights
you can actually try.

- **[watchlist.md](watchlist.md):** the short list of things worth trying, plus weekend projects.
- **Editions:** one file per week, newest first. The baseline is a full sweep; the weekly files only cover what's new.
- DCC MCP servers are tracked in the llm-dev repo (`mcp/README.md`).

A scheduled Claude task runs every Saturday morning. It researches the past
week, writes the new edition here, updates the watchlist, commits, and posts a
short summary as a Claude chat.
