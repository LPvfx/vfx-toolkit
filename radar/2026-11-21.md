# Radar: 21 Nov 2026

A modest week. The useful news is plumbing for splats: a Nuke node that turns a
CameraTracker solve into an aligned splat, 3ds Max 2027.3 with 4DGS playback and
an MCP server, and Blender 5.3 getting splat export through an add-on. On the
model side, PAN 2 (a 29B world model) went native in ComfyUI 0.46, and
LongCat-Video-Avatar 1.6 shipped under MIT. Two Mac-friendly releases the
earlier editions missed are logged as **(catch-up)**: Apple's Depth Pro 2 and
Speridlabs Idol with its MLX port.

Same conventions as before: **Mac** means the 64GB M5 Pro, and **(secondary)**
means the item was confirmed only through third-party coverage. Several
Hugging Face and GitHub pages couldn't be fetched on this run, so more items than
usual are secondary. Check the licence on the model card before using anything.

## Top picks

1. **DBS_SplatTrain (Nuke 17).** Takes an existing CameraTracker solve, writes a COLMAP dataset, trains with Brush and returns a splat aligned to the track camera. It's the first comp-native track-to-splat route. MIT, but Windows only.
2. **Depth Pro 2 (catch-up, 3 Nov).** Apple's metric depth now does video and live feeds. Four sizes from 24M to 872M, with Core ML exports and a Mac live-depth demo. **Research-only licence.**
3. **Idol + idol-sdk-mlx (catch-up, 28 Oct).** Single image to a Gaussian splat of up to about 1M Gaussians, reportedly Apache 2.0. The MLX port peaks around 7.2GB. It's the image-to-splat counterpart to SHARP on the Mac.
4. **3ds Max 2027.3 (19 Nov).** 4DGS playback from SPZ/PLY sequences, PLY export, and an integrated MCP server (tech preview). Windows only, but it's another major DCC that exposes itself to Claude.
5. **ComfyUI 0.46 (18 Nov).** Native PAN 2 support and a Video Deflicker node built on RAFT optical flow. The deflicker node is the one to try on generated plates.

## 1. Video, world models and avatars

- **PAN 2 (MBZUAI IFM), native in ComfyUI.** A 29B MMDiT world model with a frozen Qwen3.5-9B prompt rewriter and the Wan 2.2 VAE. Text or start frame to up to 20 s at 704×1248, 24 fps.
  - **ComfyUI:** loads with the stock loaders after core PR #17755 (merged 15 Nov). Comfy-Org repack: int8 26.7GB, bf16 67.4GB; int8 runs at about 15 s/step on an RTX 5090 (secondary).
  - **Why:** an open, physics-aware option for long environment and previs clips. Untested for plate work.
  - **Licence:** not confirmed on this run. Check the model card.
  - **Mac:** no. Rent a 48GB or larger card.
  - https://huggingface.co/IFM/PAN2 · https://huggingface.co/Comfy-Org/PAN2 · https://comfyui-wiki.com/en/news/2026-11-16-pan2-native-comfyui (secondary)
- **LongCat-Video-Avatar 1.6 (Meituan, 13–15 Nov).** Audio-driven portrait animation for long talking-head clips. A 13.6B base with three LoRAs, 8-step sampling and optional INT8/FP8.
  - **Why:** an open, permissively licensed digital-human baseline for previs and temp dialogue.
  - **Licence:** MIT, per the earlier model card and coverage of 1.6.
  - **Mac:** no. CUDA and FlashAttention; the examples use two GPUs.
  - https://huggingface.co/meituan-longcat/LongCat-Video-Avatar · https://alphasignal.ai/news/meituan-s-longcat-video-avatar-1-6-generates-stable-10-minute-talking-videos (secondary)
- **Apple FastFrames-L (16 Nov).** An autoregressive text-to-video model aimed at interactive latency. No resolution, length or size published, and a custom licence. Interesting for realtime and installation work if it turns out to run on Apple Silicon; nothing confirms that yet.
  - https://huggingface.co/apple/FastFrames-L · https://theopenweights.com/news/fastframes-l-z3pl (secondary)

## 2. Depth

- **Depth Pro 2 (catch-up, 3 Nov).** Metric monocular depth for single images, video (16-frame clips with 4-frame overlap, or per-frame streaming) and live feeds, plus a separate 23.5M focal-length estimator.
  - **Sizes:** S 24M, B 97M, L 334M, H+ 872M (default).
  - **Why:** metric depth with focal estimation straight from footage, for projection and layout. Its temporal stability needs testing against DA3 and Video Depth Anything.
  - **Licence:** Apple ML Research model licence, **research use only**. No training code.
  - **Mac:** yes. MPS, Core ML exports, and a live-depth demo (macOS 15+, Xcode 16+).
  - https://github.com/apple-aiml-research/ml-depth-pro-2 · https://huggingface.co/apple/DepthPro2 · https://explainx.ai/blog/apple-depth-pro-2-open-weights-metric-video-depth-focal-length-research-license-2026 (secondary)

## 3. Splats and reconstruction

- **DBS_SplatTrain 0.1.0 (19 Nov).** A Nuke 17 node by compositor David Borrull.
  - **What:** exports every Nth frame with masks, writes the CameraTracker cameras and points as a binary COLMAP dataset, trains with Brush 0.3.0 in a separate process, and returns a `.ply` aligned to the track. A button builds the GeoImport → SplatRender → OCIOColorSpace chain. Needs an undistorted plate.
  - **Speed:** about 20 min for 30k steps on an 8GB RTX 4060 Ti (author's figures).
  - **Why:** splats from the shot you've already tracked, in shot space, inside the comp.
  - **Licence:** MIT; works in Nuke Non-commercial. **Mac:** no, Windows only for now. The recipe itself (CameraTracker → COLMAP → Brush) is portable.
  - https://github.com/dborrull/DBS_SplatTrain/releases/tag/v0.1.0 · https://radiancefields.com/dbs-splattrain-turns-nuke-camera-tracks-into-gaussian-splats
- **3ds Max 2027.3 (19 Nov).** 4DGS playback from SPZ/PLY sequences on the timeline, splats in the viewport without IPR, tools to split large scenes into exportable pieces, a non-destructive Edit Point modifier, and **PLY export**. Commercial, Windows only.
  - https://radiancefields.com/3ds-max-2027-3-adds-splat-viewport-display-and-4dgs · https://www.cgchannel.com/?p=180392
- **Splat Studio 1.0.0 for Blender 5.3 (19 Nov).** Non-destructive splat edits (crop, relight, displace, adjust, reveal, cleanup) and **3DGS PLY export**, which 5.3 lacks natively. GPL, $12.99 on Superhive. **Mac:** likely.
  - https://radiancefields.com/splat-studio-brings-splat-editing-to-blender-5-3
- **Splat Repair 0.1.0 (16 Nov).** A splat editor with a repair brush, clone stamp and LaMa inpainting ("Deep Fill") for holes. Apache 2.0. Windows only; Deep Fill needs NVIDIA.
  - https://github.com/NicolasDrum/splat-repair/releases/tag/v0.1.0 · https://radiancefields.com/splat-repair-brings-a-repair-brush-to-gaussian-splats
- **SplatAnything (catch-up, 9 Nov).** Feed-forward 3DGS with "Gaussian spacing normalisation" to stop scale and viewpoint drift, from objects up to aerial and 360 scenes. Inference code and weights out; licence and hardware unconfirmed.
  - https://github.com/zju3dv/SplatAnything · https://arxiv.org/abs/2611.08264
- **Also:** 01Splat 0.5.6 is a local all-in-one splat app, but Windows/NVIDIA only and NC on the free tier (https://radiancefields.com/01splat-runs-the-full-gaussian-splatting-pipeline-locally).

## 4. Image-to-3D

- **Idol (Speridlabs, catch-up, 28 Oct) + idol-sdk-mlx.** One image to a 3D Gaussian object (32k to 1M Gaussians, standard PLY). A 370M DiT on DINOv3 and FLUX.2 VAE conditioning; about 7.2GB peak.
  - **Mac:** yes. The MLX port runs the DiT in MLX and the rest on MPS: about 65–100 s per object on an M5 Max at 50 steps. An "Idol Turbo" distillation (5 steps) is reported.
  - **Licence:** Apache 2.0 per coverage (secondary). It needs gated access to DINOv3 and FLUX.2-dev, whose own terms apply.
  - **Why:** props as splats straight into Blender 5.3 or TouchDesigner, with no mesh step.
  - https://speridlabs.com/research/idol · https://github.com/speridlabs/idol-sdk · https://github.com/ivanfioravanti/idol-sdk-mlx

## 5. Tools and ecosystem

- **ComfyUI 0.46.0 (18 Nov).**
  - **Local:** PAN 2 in core, a **Video Deflicker** node with a faster RAFT optical flow, single-channel PNG saving, a Split Image Channels node, and mesh input on Create Camera Info. DirectML support is removed.
  - **Partner (paid) nodes:** LTX AlphaGen, SDR-to-HDR, Reframe and Upscale; Bria RMBG 3.0; Seedance 2.5 Flash; Kling 4.0 Image (0.45.6). MiniMax H3 Image is there too (**H3 licence, excludes the UK**).
  - https://freedom.tech/posts/2026-11-18-comfyui-0-46-0/ · https://github.com/Comfy-Org/docs/pull/2413
- **3ds Max 2027.3 agents.** Autodesk Assistant gains a "Do work for me" tech preview (MAXScript with preview and approve, Safe Mode on), plus an integrated **MCP server** for Claude or ChatGPT, with options to sandbox or turn off writes. llm-dev `mcp/README.md` is updated.
  - https://www.cgchannel.com/?p=180392
